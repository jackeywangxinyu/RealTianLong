# tests/
> L2 | 父级: /CLAUDE.md

验收即规格。每条设计边界（预测不是事实、回忆不是现状、相信不等于真实、同意不等于发生）都对应至少一条可证伪的断言。

成员清单
__init__.py: 包标记，允许测试间相对导入共享辅助
conftest.py: 共享夹具，标准仓库场景、权威写入器、make_intent 工厂、act() 同时行动辅助
test_kernel.py: 内核规则，位置与所有权正交、门锁获知、同抢唯一物品恰一人成功且与提交顺序无关、藏匿与搜查、准入拒绝、听觉曲线、确定性、程序化世界（一半江湖化）随机行动模糊测试
test_cognition.py: 信念修正，槽位取代、传闻不覆盖亲见而并存、负证据、藏匿物豁免、候选集只依认知
test_acceptance_warehouse.py: 设计第七节验收用例端到端 + 幂等（含被拒意图）+ 第二写入者版本冲突 + 回放指纹一致
test_memory.py: 记忆层，检索边界强制过滤（他人/未来/他分支/他世界不可见）、outbox 幂等、最近缓冲弥补索引延迟、嵌入确定性
test_agents.py: 智能体层，意图 ID 按版本确定、端到端社会链条（查探→盘问→搜身→报告→质问）、无刺激时静止、完整流程下的认知隔离、调度节流、决策轨迹入检查点且长局有界
test_command.py: 输入语态验收 I01–I05，否定/条件/转述/复合/疑问不产生候选、肯定指令仍走快路径、LLM 压不过规则看见的否定且必须声明即时+玩家、LLM 失败不回退未确认候选、非即时输入不推进世界版本与时钟
test_observation.py: 观察投影验收 P01–P07，远端失败移动不泄露、锁门只在门这侧留下动作与响动、成功移动两端各得片段、传闻外观与真实外观隔离、只闻其名的外观是未知、传闻地点不触发亲眼描写、暗门不被“去某处”自动穿过、过时路线可尝试并失败
test_language.py: 语言层，规则解析表、言语与否定、陌生实体不可引用（规则与 LLM 皆然）、LLM 只在规则失败时调用且只见玩家认识的实体、叙述只含玩家感知、时辰先于所见且玩家原话只作意图、失败回退、磁盘缓存
test_session.py: 装配层，解析失败不推进时间、完整回合（NPC 扇出 + 结算 + 索引 + 叙述）、读档后向量索引从权威记录重建、.env 只补缺、命令行脚本化跑通
test_store_contract.py: 持久化契约，内存与 Neo4j 两后端跑同一组断言（往返、幂等、版本冲突、outbox、跨后端指纹/事件/信念逐字节一致、请求进度与会话运行态随提交同事务落库且逐字段往返、叙述只补写一次、存档版本往返、请求绑定在提交内检查——同 ID 的交错提交（重复投递、异内容、接不上的进度、已完结）整体回滚），Neo4j 不可达自动跳过；净差异折叠
test_render_gate.py: 文字 ≠ 事实闸门验收 L01–L02，合法修辞（含无量山满堂人物与外观描写）放行；点名清单外实体（名或别称）、状态升级（受伤→被制、略有所得→学成）、瞬移（含别称）、物品复制、编造承诺、传闻去归属各被拦下；词法回归——“不慎/毫不犹豫/无奈/无量山”遮不住关键词、双重否定算肯定、常见不连续说法（受了点伤、点了你的穴道、学会、练熟）、更多抵达动词、“还有一把”算复制、“知道/一言不发”不算归属，而“控制住/林中毒蛇/答应了一声/一定会有用”与门名里的地名不误报；叙述者回退模板且来源分开记录，世界照常只结算一次；对白多出承诺/外人/状态或丢了主语即回退模板，说话者没听说过的场景实体（名或别称）同样回退
test_resume.py: 恢复验收 R01–R04，快照映射不可就地修改且 pickle/deepcopy/JSON 往返；连续运行 vs 中途关闭（含看完开场、首回合前就关闭）再读档的事件、调度、认知、叙述、会话运行态逐项一致（内存必跑，Neo4j 可达同跑），不恢复会话运行态则调度与叙述分叉（反例对照）；同请求返回既有结果、同 ID 异内容冲突、解析失败不落请求；并发的重复投递（一个或两个会话）只结算一次、异内容显式冲突，重试一个仍在进行的多 tick 等待不多走 tick；索引/叙述故障注入后重试不二次结算，多 tick 等待中途崩溃只走剩下的 tick；存档版本不符即拒绝、迁移须显式
test_learning.py: GNN 层，特征语义（极性/方向）、张量级认知隔离、批处理指针偏移、角色标签保留“未知”、小规模训练胜过“不变”基线、词表过期的检查点在加载时被明确拒绝、GNN 预测器接入决策图
test_rl.py: RL 层，观测合乎空间且掩码=候选集、奖励语义（进展/损失/冤枉人）、模仿学习可学、不被“示范几乎全是等待”骗过（按原比例学不到任何动作，平衡后学到）、评测报告冤枉人与动手次数、学得的策略接入决策图且意图仍经内核结算、PPO 冒烟（slow）
test_wuxia_rules.py: 武侠机制，暗门夜现且不入环顾、断崖单向、伤→制→限时自解、闪避、吸功、毒与解药、搜走被制者之物、研读累积且私密、江湖层叠加不改底图、私密属性永不外泄
test_wuliang.py: 天龙八部·无量山验收，世界自洽、开场冲突链涌现（寻衅→放貂→护短→搜出解药→救治）、入夜私奔按约动身、玩家可循原著路线学成凌波微步、外观只在初见时描写
test_isolation.py: 性质测试，扰动角色未观察的真相后其认知与认知视图逐字节不变；感知不带溯源字段；响动不泄露行动者
