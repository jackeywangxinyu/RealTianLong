# language/
> L2 | 父级: /CLAUDE.md

开放语义与文字表达。LLM 只做两件事：把玩家的自由文本解析为结构化意图、把已经成立的事件按玩家可见范围写成文字。它永远不裁定事实；任何模型输出都要回到 kernel 结算。文字 ≠ 事实：模型成功返回的非空文字也要先过 render 的确定性语义闸门，命中即回退模板——提示词只是请求，闸门才是验收。

成员清单
templates.py: 确定性文本层（无 LLM），render_fact/render_event/render_experience/render_percept 角色视角措辞（名称表即观察者的实体草图，按种类说"在桌上/在身上"）+ 失败原因/研读进境（未贯通者明说未贯通，免得润色时被夸成学成）/武侠状态措辞 + 没有原话的言语按言语行为写成动作（SOCIAL_VERBS：“向钟灵打了个招呼”，耳语才是“低声说了些什么”）+ 自己移动只写“来到”（步态留给原话），旁人推门未果只写“走向那道门” + 事件后果（伤毒被制、学成、暗道与藏匿之物）；memory、speaker、narrator 共用
llm.py: LLMClient 协议（generate + stream）+ GeminiClient（REST，密钥只从环境变量读；每线程一条 HTTPS 长连接、经代理走 CONNECT 隧道；显式思考档位，接口不认即去掉重试；SSE 流式；型号不可用退回 -latest 别名；每次调用记首字与总耗时 CallStat）+ CachedLLM 磁盘缓存（只在 TIANLONG_LLM_CACHE=1 时启用）+ ScriptedLLM 离线脚本回放（可模拟延迟与流式）+ llm_from_env()（叙述模型，默认 gemini-3.8-flash、思考 low）/ fast_llm_from_env()（解释用快模型，默认 flash-lite、思考 minimal）；任何失败抛 LLMUnavailable，调用方必须回退模板
speaker.py: Speaker 协议 + TemplateSpeaker + LLMSpeaker，把结构化言语行动说成符合人设的一句话；事实以命题为准，原话只是修辞；LLM 润色须过对白闸门（只许点名说话者、听者、话题主语与宾语——名或别称，不许多出意图里没有的承诺与状态，必须提到话题主语——本人可称“我”、听者可称“你”），否则回退模板；拒绝全集是会话交来的场景全部实体名与别称加说话者认识的名字，说话者没听说过的真实实体同样不许点名：原话随意图落库、被听者记住，再被叙述者当作有出处的名字照搬，分歧一旦提交就撤不回
command.py: 语态分析，analyze() 在选操作之前判定这句话是不是“玩家此刻要做的一件事”——否定作用域（跨情态词与介词短语回溯，双重否定判为不确定）、条件/计划/斟酌、转述（他人作主语或过去时标记）、引语、复合分句（言语动词之后的内容不算行动）、可行性疑问；言语行为词 SOCIAL_WORDS（打招呼/赔罪/救命……→ Social，归 TELL）与姿态词 GESTURE_WORDS（打量/坐下/拱手……，归 WAIT）也是行动词，盖住里面的单字（“打招呼”不是打、“救命”不是救、“坐下”不是下），同样受否定与条件约束；action_hits() 给出去掉引语与被长词覆盖之后的命中；ParsedCommand 保留语态、主体、否定操作、条件与分句跨度；clarify() 给出不推进时间的追问
parser.py: Parsed（含 MoveKind：行动/说话/姿态/问主持人/元指令/听不懂，多步行动的 followups，问主持人的原话 question）+ rule_parse 语态闸门 → 规则解析（只收单一、肯定、即时的指令，按优先级尝试所有命中关键词的操作，都不成时给最具体的场内追问；结果带类别：言语=SAY、姿态=GESTURE）+ IntentParser（规则失败或非即时语态才调 LLM，JSON Schema 约束，必须声明 mode 与 actor，只有 immediate+player 被接受，且压不过规则看见的否定；LLM 失败绝不回退到未经语态确认的候选）；可引用实体只来自玩家认知图（场景别称只对已认识的实体生效）；规则层修掉的误判：打招呼/打量不是动手、看人是打量而明说“搜”才搜身、向人磕头是服软姿态（独自磕头仍是原著路线的查看）、大喊救命/用易经挡脸不是施用、点了不认识的名字不默认手里那件、言语只有说清“谁在哪/在哪”才带命题，原话只引说出口的那句（speech_line），没有听者的言语行为是当众姿态；normalize() 让 MOVE 绑定玩家知道的路（“朝门走”= 经这扇门去对面，“去某地”= 经认为连通的门，点名的门不通就换一条，目的地是脚下不算移动，不知道路就追问），leave_here() 只有一条出路才替人走；wield_problem() 拦“掏出/拔出”不在身上的东西；等待可带时长或“等到天黑”；规则机件（mentions/held_items/exits/invalid/manner_of/speech_manner/wait_length/unwrap_line/pose_of）供解释器复用
interpret.py: 主持层解释器 Interpreter（设计 §4.1），interpret(text, me, recent) → Parsed：GM:/OOC: 前缀与明显的场外问题 → ASK_GM，/hint /recap /beliefs → META（都不调模型、不推进时间）；高精度规则快路径只收整句命令（实体换成占位符后整句匹配白名单，再交 rule_parse 定角色，单字关键词从不单独成立，亚毫秒、0 次模型调用）；其余一次快模型 generate（JSON Schema、max_tokens 300、中文系统提示），把任何第一人称输入归为 act（1~3 个内核步骤）/ say（听者 + 去掉包装的原话 + 言语行为 + 可选的“谁在哪”命题）/ gesture（不带主语的姿态）/ ask_gm / unclear，并声明语态与主体；逐项校验——实体须是玩家认识的且种类对、MOVE 经 normalize、要在手里的须在（计划里先拿起的也算）、第一个不成立的步骤截断计划、一步不成就给场内说法不推进（编造前提的防线，不回显模型编的 id）；提示词只含玩家认识的实体（点名、此地与在场、出路优先，至多 40 个）、身上的东西、会的武功与最近两段正文；没有模型或模型失败退回 IntentParser
narrator.py: Narrator 主持人之声，输入只有玩家本回合的感知与会话交来的 SceneBrief（台词、最近正文、玩家原话、钩子），台词本身算出处；模板先写成事实清单（fact_lines 由 render 提供、此处再导出；自称改为“你”，移动/查看后附所见，去重），清单里的 NPC 言语换成 render_voice() 的带言语行为台词（“龚光杰冷笑着向你叫阵：……”，闲话只写言语行为，措辞按语义输入确定轮换）；narrate_scene() 有模型时流式生成（无 stream 则 generate），逐句对“已交付 + 本句”跑 check() 与台词闸门 check_quotes()、再查钟点数字，通过即经 on_text 交付、违规即丢弃并记下，一句未过或丢满两句补上模板（已交付过正文的换行后只补清单与台词），传闻归属收尾整段查，模型中途失败保留已交付的并补模板；Rendered（template / llm / gated_fallback / llm_unavailable + 违规明细）的 text 恒等于交付的全部文字；narrate_rendered()/narrate() 以空 SceneBrief 委托之；系统提示定下第二人称、80~250 字、台词写成“某某道：“……””、只许点名可点名的、不替玩家开口或拿主意、避开最近正文的句式与套话、不写钟点、停在钩子上；用户提示依次是最近三段正文（每段末尾约 300 字，钟点换成时辰文字）、玩家原话、事实清单、要说出口的话（腔调/谈资/回应/可点名）、初见外观、眼下处境；玩家原话只作意图与姿态，等待后的时辰排在所见之前；lore_keys() 只由亲眼所见触发（言语与响动里的实体、门那头与别人走向的地点都只闻其名，不描写；夜里取月下变体），外观描写只在初见时给出；世界前提与文风来自场景
render.py: 文字 ≠ 事实闸门。fact_lines() 事实清单；RenderPlan/build_plan() 由与清单相同的输入推出本回合允许点名的实体与其别称、其余实体的别称（两字以上，只用于拒绝）、确实出现的状态（伤/毒/被制/学成）、真的到达的地点（含别称）、物品件数、传闻说话者与出处原文，承诺恒不存在；check() 词法拦截六类错误——点名清单外实体（名或别称；全集含场景全部实体名，只用于拒绝）、状态升级、瞬移（在全部名字上最长匹配，门名不被截成地点）、物品复制（含“还有/另有/又……一把”）、编造承诺、传闻去掉归属（言说动词按词形认，“知道”“一言不发”不算）；check_utterance() 为对白闸门；check_quotes() 为台词闸门——每段引语（含无引号的“某某道：……”）归到引子小句的主语（宾语标记、“的”字结构、感知动词、“你”只在小句开头才是主语），句首引语看其后的“某某喝道”或沿用上一段的说话者；归到玩家名下的须是玩家本回合的原话（puppet，引号外的“你当即决定/心想”同样算），NPC 只许点名 may_name ∪ 说话者/听者/玩家 与自己说法里的名字（quote_entity）、只许计划里有的状态（quote_status），确凿归到本回合没开口的人名下即 voice，归属不明取所有说话者许可的交集，清单与外观描写里原样有的引语不另查，since 只查新句；sentence_ends() 流式分句（引号内不断句，收引号后带言说动词的小句是归属、以冒号收尾的是下一段引子，结尾不定则等下一段）；RenderPlan 另记观察者本名、认识的人（称呼→本名）与本回合开口的人；词表集中为数据：词条是正则片段（不连续说法如“受了点伤”“点了你的穴道”），每类另有排除复合词（“控制住”“林中毒”“答应了一声”）；否定只认紧贴关键词的否定词（隔至多几个虚字，双重否定算肯定，“离融会贯通还差一层”算没到，“不慎”“无奈”“无量山”不遮住关键词），出处（清单、外观描写、原话里本就有的说法）不算违规；局限如实写在 L3 头部
scene.py: 主持层契约 VoiceLine（一句要替 NPC 说出口的话：说话者、听者、言语行为、命题说法或闲话、模板原话、腔调、谈资、许可点名的名字、回话的由头）/ SceneBrief（本回合叙述上下文：要说的话、最近几回合正文、玩家原话、眼下的钩子）/ TextSink（流式交付回调）；会话只用已落库的数据拼出它
__init__.py: 包入口
