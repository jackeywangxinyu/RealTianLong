# scenarios/tianlong/
> L2 | 父级: /src/tianlong/scenarios/CLAUDE.md

天龙八部世界，以金庸《天龙八部》世纪新修版为蓝本，按剧情区域逐幕构建。每一幕只摆好世界、角色目标与各自所知，不写剧本：原著情节应当能由规则内核与角色认知涌现出来，而玩家可以走向原著之外。文字素材为原创转述，只描写看得见的样子，不预告剧情、不泄露他人心思。

第一幕·无量山：比剑方罢的剑湖宫、后山禁地、只能下不能上的断崖、崖底剑湖与月夜显影的无量玉璧、玉璧旁夜里才看得见的石缝、琅嬛福地里的玉像与两卷帛书（北冥神功 → 吸功、凌波微步 → 闪避）、只能出不能进的山腹隧道、围山的神农帮。

成员清单
wuliang.py: build_wuliang()，10 处地点、10 条通道（含单向断崖与隧道、夜现暗门）、10 个角色的身手与目标（龚光杰寻衅至段誉受伤、钟灵护着段誉、左子穆与同门互为盟友、干葛二人 19:20 私奔灭口、神农帮守营守道）与各自所知
lore.py: SETTING 世界前提、STYLE 文风、LORE 外观描写（"id@night" 为月下变体）、ALIASES 别称、HINTS 指令示例
__init__.py: 包入口
